### ⭐ Option 1: Easiest (One Command)
```bash

start.bat
```
Then visit: http://localhost:8000/docs

### Option 2: Manual Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
cd app
python main.py
```

### Option 3: Docker
```bash
cd backend
docker build -t ats-backend .
docker run -p 8000:8000 ats-backend
```
